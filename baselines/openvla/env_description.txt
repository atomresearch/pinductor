A Blocks World manipulation task. A gripper moves along a row of columns; each column holds a vertical stack of distinct numbered blocks (bottom to top). The goal is to rearrange the blocks into a fixed target configuration; the task is solved the moment the stacks match the target and the gripper holds nothing. There are 4 actions: 0, 1, 2, 3. Two of them move the gripper between adjacent columns (left / right) and two manipulate blocks (pick up the top block of the current column / put the held block down on the current column). Work out the exact effect of each action - including when an action does nothing - from the demonstrations. The gripper observes ONLY the stack at its current column plus the block it is holding; it never sees its absolute column index or the other columns, and its starting column is unknown. Reward is sparse and terminal: +1.0 on the step that reaches the target configuration, 0.0 otherwise. Concretely, EACH EPISODE the 6 blocks (numbered 1..6) START in a FRESH RANDOM configuration: they are scattered uniformly at random across the 3 columns, in random stacking order (any arrangement of the 6 blocks over the 3 columns is possible), the gripper holds nothing, and the gripper's STARTING COLUMN is uniformly random in {0,1,2}. The TARGET configuration (fixed across episodes) is: column 0 = [1,2,3,4,5,6] (block 1 at bottom, then 2,3,4,5, and 6 on top) - i.e. the sorted tower - columns 1 and 2 empty. The initial-state model must reproduce this DISTRIBUTION: random stacks over the 3 columns each episode, random gripper column, fixed target.
